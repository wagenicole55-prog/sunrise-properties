# Sunrise Properties — standalone Netlify build

Standalone Vite/React + Netlify Functions build for the U.S.-nationwide Sunrise Properties marketplace.

- Target: https://sunriseproperties.netlify.app
- Build: npm run build
- Publish: dist
- Functions: netlify/functions
- Auth: Netlify Identity
- Data: Netlify Blobs
- AI: Netlify AI Gateway
- Payments: Paymegate server-side

Required Netlify account setup: enable Identity and add PAYMEGATE_API_KEY as a Functions environment variable. Never commit the Paymegate key. AI Gateway requires a production deploy and a credit-based Netlify plan.
